# 🌌 Space Explorer – Interactive Solar System Website

A beautiful, educational, and fully interactive Solar System explorer built with **pure HTML, CSS, and JavaScript** – no external libraries or frameworks.

Live Demo: https://vikmelf.github.io/space-explorer/

## 🚀 Features

- **Animated Solar System model** on the home page with orbiting planets, realistic rotation effects, glowing atmospheres, and hand-crafted Saturn rings – all made with CSS gradients and animations.
- **Detailed planet pages** featuring high-quality NASA images (local PNGs with transparent backgrounds for perfect rendering).
- **Rich information sections** for each planet and the Sun: description, key parameters, and a collection of interesting facts.
- **Multilingual support** (English, Ukrainian, Polish, German) with a flag-based language switcher in the top-right corner. The selected language is saved and persists across pages.
- **"About the Website and Developer"** page with a personal story and project description (also multilingual).
- Fully responsive design – works great on desktop and mobile devices.
- Starry background created with HTML5 Canvas for an immersive space feel.
- Smooth hover effects, clickable planets, and a "Back" button on every page.

## 🛠️ Technologies Used

- HTML5
- CSS3 (animations, gradients, flexbox, canvas styling)
- Vanilla JavaScript (DOM manipulation, localStorage for language persistence, URL params)
- NASA public domain images

No frameworks, no build tools – pure, lightweight, and performant code.

## 🌍 Multilingual Support

The site supports four languages:
- English (default)
- Ukrainian
- Polish
- German

Language is selected via flag icons and saved in localStorage, so the choice persists when navigating between pages.
